1. What Is Programming?
Programming is the process of giving instructions to a computer to perform a specific task or solve a problem.

2. What Is a Programming Language?
A programming language is a language used to communicate with a computer by writing instructions in a format that the computer can understand and execute.

3. What Is Python?
Python is a high-level, interpreted programming language. It is easy to learn and understand. We use Python to develop applications, websites, automate tasks, and solve problems.

4. What Is Syntax?
Syntax is the set of rules we must follow while writing code in a programming language. It tells us how to write instructions correctly.

5. Programming and Python
Difference between programming and Python:

Programming is the process of creating instructions to solve problems, whereas Python is a programming language used to write those instructions.

6. What Remained the Same?

7. What Changed?
The way we wrote the instructions changed. Pseudocode uses simple English statements, whereas Python uses proper programming syntax and rules to execute the instructions.
